 # Blood Donation Web Platform

![Blood Donation](https://img.shields.io/badge/Project-Blood%20Donation%20Platform-red)
![License](https://img.shields.io/badge/License-MIT-blue)
![Status](https://img.shields.io/badge/Status-Active-brightgreen)

A comprehensive web platform connecting blood donors with recipients to streamline the blood donation process and help save lives.

## 🩸 Overview

The Blood Donation Web Platform is a community-driven initiative designed to bridge the gap between blood donors and those in need. Built with modern web technologies, this platform offers real-time donor matching, profile management, and location-based services to make blood donation more accessible and efficient.


## ✨ Features

- **User Authentication & Profiles**
  - Secure login/registration system
  - Comprehensive donor/recipient profiles
  - Blood type matching algorithm

- **Donation Management**
  - Schedule and track donations
  - Appointment reminders
  - Donation history and achievements

- **Location Services**
  - Find nearby donation centers
  - Emergency request mapping
  - Distance-based donor matching

- **Community Engagement**
  - Donation events and campaigns
  - Educational resources
  - Donor recognition system

- **Admin Dashboard**
  - User management
  - Donation analytics
  - Content management system

## 🚀 Tech Stack

- **Frontend**
  - HTML5, CSS3, JavaScript
  - React.js
  - Bootstrap for responsive design

- **Backend**
  - Node.js with Express
  - MongoDB for database
  - JWT for authentication

- **Other Tools**
  - Google Maps API for location services
  - Twilio for SMS notifications
  - Chart.js for analytics

## 📋 Prerequisites

- Node.js (v14 or higher)
- MongoDB
- NPM or Yarn
- Git

## 🔧 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/BalajiJangili/Blood-donation-web.git
   cd Blood-donation-web
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

4. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

5. **Access the application**
   - Open your browser and navigate to `http://localhost:3000`

## 📱 Usage

### For Donors
1. Create an account and complete your donor profile
2. Set your blood type, location, and availability
3. Receive notifications for nearby donation requests
4. Schedule donations and track your donation history

### For Recipients
1. Register as a recipient and verify your identity
2. Create blood requests specifying type, quantity, and urgency
3. Get matched with compatible donors in your area
4. Receive real-time updates on your request status

### For Administrators
1. Access the admin portal using authorized credentials
2. Manage users, donation centers, and blood inventory
3. Generate reports and analyze donation patterns
4. Coordinate donation campaigns and events
